# 🧮 Python History Calculator

### 💻 A Simple Interactive Calculator Built with Python

## 📌 Project Overview

The **Python History Calculator** is an interactive calculator developed using **Python and Jupyter Notebook**. It performs basic arithmetic operations and maintains a history of previous calculations, making it easy to review past results.

## ✨ Features

- ➕ **Addition** – Performs addition of numbers.
- ➖ **Subtraction** – Calculates the difference between numbers.
- ✖️ **Multiplication** – Multiplies two numbers.
- ➗ **Division** – Divides numbers with zero-division handling.
- 📜 **Calculation History** – Stores and displays previous calculations.
- 🗑️ **Clear History** – Allows users to clear calculation history.
- ⚠️ **Error Handling** – Handles invalid inputs and division by zero.

## 🛠️ Technologies Used

- 🐍 **Python**
- 📓 **Jupyter Notebook**
